# Version 0.3.1 — scoped heartbeat maintenance fix

Completed: 2026-10-09T01:03:56.200621+00:00

An external audit reported by the user identified a timeout under Lean's
default asynchronous elaboration. It was reproduced on the exact v0.3.0
source with the pinned Lean 4.34.1 / Mathlib versions:

```sh
lake env lean -j1 RP2/TetrahedralPaths.lean
```

The pre-fix compilation exited 1 with a deterministic `whnf` timeout at
200,000 heartbeats. The existing full-audit scripts use `-DElab.async=false`,
which explains why this default-elaboration failure was not caught there.
Heartbeats measure computation allocations, not elapsed wall-clock time.

The sole change to the 66 mathematical source modules is:

```lean
set_option maxHeartbeats 400000 in
```

scoped to `RP2.Rotation.tetraLinearIsometry_eq_three_rotations`, before its
doc comment. No theorem statement, proof script, import, dependency pin,
axiom, or trust assumption changes. The standalone file was regenerated.
